unofficial udpspeeder packages

A personal feed. Built and signed by David Connolly. Not affiliated with, endorsed by, or supported by the OpenWrt project. Report problems at connollydavid/UDPspeeder-simd.

Two packages, both from a source snapshot: udpspeeder-snapshot, the stock tunnel, and udpspeeder-simd-snapshot, the SIMD fork. Adding this feed installs nothing on its own.

OpenWrt snapshot (apk)

wget -O /etc/apk/keys/udpspeeder-simd.pem \
  https://connollydavid.github.io/UDPspeeder-simd/feed/apk-public-key.pem
echo "https://connollydavid.github.io/UDPspeeder-simd/feed/main/$(apk --print-arch)/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list
apk update

udpspeeder-snapshot

The stock tunnel built from a source snapshot newer than the 20230206.0 the official feed carries. It is a separate package, so it never wins an upgrade against OpenWrt's, and it conflicts with it because both own /usr/bin/udpspeeder. Swap deliberately:

apk del UDPspeeder
apk add udpspeeder-snapshot

or on 24.10

opkg remove UDPspeeder
opkg install udpspeeder-snapshot

It keeps /etc/config/udpspeeder and /etc/init.d/udpspeeder, so your existing settings carry across the swap.

udpspeeder-simd-snapshot

The SIMD fork, built from a source snapshot rather than a release tag, so a fix can be tested before it is tagged. It conflicts with udpspeeder-simd, which owns the same paths, and that package is not offered here: it is under review for the official feed and the name belongs to OpenWrt.

apk add udpspeeder-simd-snapshot

or opkg install udpspeeder-simd-snapshot on 24.10.

It checksums the wire with CRC32C where udpspeeder uses CRC-32, so the two do not interoperate. Run it at both ends of the link.
