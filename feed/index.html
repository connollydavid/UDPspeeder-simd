udpspeeder-simd and udpspeeder

A personal feed. Built and signed by David Connolly. Not affiliated with, endorsed by, or supported by the OpenWrt project. Report problems at connollydavid/packages.

udpspeeder-simd is the SIMD fork, which is in no feed yet. UDPspeeder is the stock tunnel, built from a source snapshot newer than the 20230206.0 the official feed carries. Because it is newer, enabling this feed makes it the UDPspeeder your router installs and upgrades to, until OpenWrt ships one newer still.

OpenWrt snapshot (apk)

wget -O /etc/apk/keys/udpspeeder-simd.pem \
  https://connollydavid.github.io/UDPspeeder-simd/feed/apk-public-key.pem
echo "https://connollydavid.github.io/UDPspeeder-simd/feed/main/$(apk --print-arch)/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list
apk update && apk add udpspeeder-simd UDPspeeder

Usage

Settings live in /etc/config/udpspeeder-simd. Set enabled 1, server 1 on one end and server 0 on the other, and give both ends the same key, fec and mtu. Then

/etc/init.d/udpspeeder-simd enable
/etc/init.d/udpspeeder-simd start

This build checksums the wire with CRC32C where the stock udpspeeder uses CRC-32, so the two do not interoperate. Run this package at both ends. It installs alongside udpspeeder without conflicting.

The stock UDPspeeder keeps its own /etc/config/udpspeeder and /etc/init.d/udpspeeder, so it drops in where the official package was.
